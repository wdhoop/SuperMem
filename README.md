SuperMem 超级记忆系统 (MVP版)


基于图数据库与向量检索的语义记忆存储平台


⚠️ 关于MVP版本


这是最小可行版本，仅包含核心架构的基础实现，用于验证设计思路。


生产级特性如完整衰减公式、混合语义排序、自进化引擎等暂不对外开放。


🧠 核心特性


模块	说明
语义节点存储	支持事件/洞察/任务/决策四种节点类型，基于语义而非关键词
线性因果链	节点间可建立因果连接，支持向前/向后双向追溯
基础遗忘机制	基于时间的权重衰减模型，模拟人类记忆遗忘规律
向量检索引擎	内置BGE向量模型，支持语义相似度搜索
RESTful API	标准HTTP接口，便于与其他系统集成
3D图谱可视化	力导向图直观展示记忆网络结构


🎯 设计理念


记忆不是数据的简单存储，而是一个活的网络：


每个节点都有自己的生命周期
重要的记忆会被强化，不重要的会自然消退
新的记忆会自动与旧记忆产生关联
系统具备自我修复和优化的能力


🚀 快速开始


bash
# 安装依赖
pip install -r requirements.txt

# 启动服务
python server.py --port 8765

# 访问界面
open http://127.0.0.1:8765



📡 API 接口


plaintext
GET  /api/health          # 健康检查
GET  /api/summary         # 系统概览
GET  /api/search?q=xxx    # 语义搜索
POST /api/nodes           # 创建节点
POST /api/edges           # 创建连接
POST /api/extract         # 从文本提取记忆

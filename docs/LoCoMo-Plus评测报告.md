# SuperMem 记忆系统 × LoCoMo-Plus 评测报告

> 对应版本：SuperMem **1.0.1**（本报告与 1.0.1 版一起发布）
> 评测日期：2026-10-17 ~ 2026-10-19

## 一句话结论

**SuperMem 记忆系统在 LoCoMo-Plus（西安交大认知记忆基准，401 条）上取得 55.86%，达成官方参考成绩（61.6）的 91%**——且是在"只给检索片段、不给完整对话"的约束下，比官方评测条件更严苛。

## 三个数字，三档口径（全程透明可复现）

| 检索策略 | 成绩 | 含义 |
|---|---|---|
| 纯系统检索（无任何增强） | **101/401 = 25.19%** | 记忆系统自身（向量+图谱+原文层）的真实底分 |
| 纯检索 + 图遍历扩展 | **106/401 = 26.43%** | 系统静态检索策略的上限（+1.2 点，几乎无增益） |
| **联想桥（检索策略升级，定稿）** | **224/401 = 55.86%** | 检索管线加 LLM query 生成（HyDE 同类）后 |

**增益 30.7 个点全部来自检索策略升级，不是系统图谱遍历能替代的。**

## 为什么不能直接和官方 61.6 比？

- **官方评测把完整对话喂给模型**（全量供给，模型从 20+ 轮对话里自己推理隐藏关联）；
- **我们的评测只给检索出来的片段**（模拟真实记忆系统的使用方式）——模型看不到完整对话，全靠记忆系统把正确的记忆"捞"出来供给它。
- 官方 61.6 证明的是"模型看完整对话能推理得多好"，我们 55.86% 证明的是"记忆系统在看不到完整对话时，能把关键记忆供给得多准"。
- **这不是同一场比赛**：一个是"全知视角上限"，一个是"回忆能力测试"。91% 达成度意味着：**在真实场景（没有完整对话可查）下，SuperMem 的回忆供给能力已经接近"作弊式全量供给"的 9 成。**

## 分类型拆解（强弱项诚实公开）

| 关系类型 | 纯系统 | 联想桥 | 说明 |
|---|---|---|---|
| causal（因果） | 34.7% | **77.2%** | 强项：跨时间因果关联供给能力最好 |
| state（状态） | 31% | 69% | 稳定 |
| goal（目标） | 13% | 37% | 短板：隐藏目标关联最难捞 |
| value（价值观） | 22% | 40% | 短板：抽象原则↔具体时刻的跨粒度匹配 |

goal/value 是公认难点（官方成绩主要也靠模型全量推理），我们做了两轮专项强化实验：goal 的"具体对象化"联想有效（+6），value 的两类强化均无效——失败机制已定位并如实记录，不藏。

## 评测设置（可复现）

- **数据**：LoCoMo-Plus 官方 401 条（causal 101 / state 100 / goal 100 / value 100），每条独立隔离评测库（生产版完整架构复刻，非 MVP）
- **评测口径**：给前提（检索片段）+ 让模型基于相关记忆回答 + 独立 judge 判定
- **回答模型**：DeepSeek V4-flash（天网云端同源模型）
- **联想生成器**：DeepSeek chat（无思考模式，快 30 倍且质量更好）
- **一致性**：parse_fail 全部清零，judge 结果经独立脚本重算一致，无取巧
- **全部脚本**：`benchmark/scripts/locomo_plus/`（ingest → 联想生成 → 评测 → judge，全断点续写）
- **全部中间产物与结果**：`benchmark/results/locomo_plus/`（联想句、评测原始结果、judge 结果，JSONL 格式）

### 补充实验（排除法，结论已固化）

| 实验 | 结果 | 结论 |
|---|---|---|
| goal/value 专项强化（GV，200 条） | 79/200 | goal 具体对象化联想有效（+6） |
| value 强化 2.0（原则冲突/来源联想，100 条） | 39/100 | value 短板不是联想角度不够，是"抽象原则↔具体时刻"跨粒度匹配问题，搁置 |
| 纯系统图遍历对照（无 LLM，401 条） | 106/401 | 隐藏抽象关联不是任何静态索引/边/向量能建的——止损项 |

## 对记忆系统的反哺（1.0.1 新增能力）

评测的最大成果已回写生产，成为 **1.0.1 版的核心新能力**：

**联想检索（associative retrieval，HyDE / query-expansion 同类）**
- `search_strong(..., expand=True)` 可选启用：检索时用"无思考模式"LLM 生成联想句扩展查询，与原查询合并召回
- 默认关闭（`config.ASSOC_ENABLED=False`），未配置/生成失败时静默回退，**旧行为完全不变**（已逐字节验证）
- 配置项：`ASSOC_ENDPOINT` / `ASSOC_KEY` / `ASSOC_MODEL`（OpenAI 兼容端点即可，本地/云端都行）
- 验证脚本：`scripts/verify_assoc_backport.py`（默认/回退/启用三态行为验证）

**止损结论（公开）**：别在"建边"、"图遍历多跳"、"value 类强化联想"上继续投入——评测已实锤无效或低效。

## 对外一句话版

> 记忆系统不是"记住"就完了，关键在"回忆时能不能捞对"。SuperMem 在 LoCoMo-Plus 上，不给完整对话只靠回忆检索拿到 55.86%（官方全量供给 61.6 的 91%），其中纯系统底分 25.2%，检索策略升级贡献 +30.7 点——差距在哪、强项在哪、短板在哪，全部透明公开，欢迎复现。
